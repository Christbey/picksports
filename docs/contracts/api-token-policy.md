# Finite API token contract

Finite issuance is controlled by a default-off activation gate. Server-owned interactive and read-only profiles use bounded issuance and exact epoch expiry; marked-token enforcement remains active even when new issuance is disabled. Legacy credentials retain honest nullable expiry metadata. This contract does not establish that permanent wildcard credentials have been eliminated.

Before activation, qualify compatible authentication workers, connection boundaries, current additive schema, rollback retention, pruning backlog and existing-client migration. Preserve browser sessions, native refresh and OAuth contracts. Do not erase policy markers or infer finite expiry for historical rows.
