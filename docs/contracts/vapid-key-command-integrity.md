# VAPID key generation and rotation

The key command validates bounded mailto or HTTPS subjects and refuses environment-syntax control characters. Writing to a configured environment file requires an ordinary bounded readable file, checked same-directory temporary replacement and private permissions. Replacing either nonempty key requires explicit --write --rotate. Nonwriting export intentionally returns newly generated key material for secure operator installation; writing must not print the private key.

Key generation is not a connectivity test or deployment. Coordinate configuration-cache propagation and browser re-subscription for rotation. The command does not serialize arbitrary external editors, migrate existing subscriptions or certify provider delivery. Never rotate real keys merely to verify the command.
