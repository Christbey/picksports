# Player prop correction boundaries

Corrections preserve immutable entry evidence and append grade history while maintaining the supported current projection. Use the owning explicit identity and correction procedure; do not infer an authoritative provider revision from local write order. Missing historical links or observations require review rather than a guessed remap.

This contract does not add universal stat-change rediscovery, all-sport eligibility or a history UI. Existing market mapping and unsupported paths remain explicit. Downstream correction cannot manufacture missing ingestion evidence. Provider acceptance, automatic backfill and deployment remain separate decisions.
