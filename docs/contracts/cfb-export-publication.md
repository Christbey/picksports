# CFB export publication contract

A durable export requires acknowledged data and manifest writes, exact bounded length/hash checks and a persisted registry winner matching the intended dataset identity and storage metadata. Open streams close in finally. Manifest object keys bind their own content hash; identical retries may reuse matching legacy keys.

A false upload or mismatching registry winner cannot report successful publication. Preserve local recovery output and shared content-addressed objects on partial failure rather than deleting them blindly. Empty exports do not publish a shared empty dataset. These controls do not authorize training, provider access, deployment or model promotion.
