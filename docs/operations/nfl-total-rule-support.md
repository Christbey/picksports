# NFL total-rule direction support

Private candidate reviewed November27, 2026.

A total recommendation requires the existing matching market-edge reason code. Each matched rule is then checked using its own name and label: a standalone opposite over/under token cannot be borrowed from global reason codes, and ambiguous rules containing both directions are excluded. Direction-neutral rules retain their existing eligibility, including the generic total-market-edge rule. Underscores, spaces, hyphens and punctuation delimit direction tokens; unrelated words such as turnover do not count.

This filters support attached to a recommendation and historical total report. It does not change rule configuration, model probabilities, calibration, grading thresholds or stored approval statuses. The actual configured rule engine reproduced the opposite-side attribution before the fix.
